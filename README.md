## 🏛️ วิวัฒนาการแบบจำลองอะตอมทั้ง 5 ยุค (The 5 Historical Models)

### 1. ⚪ แบบจำลองอะตอมของดอลตัน (John Dalton, ค.ศ. 1803)
* **แนวคิดหลัก:** อะตอมเป็นทรงกลมตันขนาดเล็กมากที่สุด แบ่งแยกไม่ได้ และสร้างขึ้นใหม่หรือทำลายไม่ได้ (Solid Sphere Model)
* **การแสดงผล 3D:** ทรงกลมตันเรียบเนียน มีแสงสะท้อนทรงกลม ไร้อนุภาคภายใน สื่อถึงจุดเริ่มต้นทฤษฎีอะตอมยุคใหม่
* **ข้อจำกัด:** ต่อมาค้นพบว่าอะตอมสามารถแบ่งแยกได้เนื่องจากมีอนุภาคย่อย (อิเล็กตรอน, โปรตอน) อยู่ภายใน

### 2. 🥧 แบบจำลองอะตอมของทอมสัน (J.J. Thomson, ค.ศ. 1904)
* **แนวคิดหลัก:** แบบจำลองขนมปังลูกเกด (Plum Pudding Model) เนื้อของอะตอมเป็นทรงกลมมีประจุไฟฟ้าบวกกระจายสม่ำเสมอ และมีอิเล็กตรอน (ประจุลบ) ฝังตัวอยู่ทั่วไป
* **การแสดงผล 3D:** ทรงกลมโปร่งแสงสีแดงระเรื่อ (เนื้อประจุบวก) มีเม็ดอิเล็กตรอนสีฟ้าเรืองแสงกระจายฝังตัวอยู่ภายใน
* **ข้อจำกัด:** ไม่สามารถอธิบายการทดลองยิงอนุภาคแอลฟาผ่านแผ่นทองคำเปลวของรัทเทอร์ฟอร์ดที่เกิดการสะท้อนกลับได้

### 3. 🎯 แบบจำลองอะตอมของรัทเทอร์ฟอร์ด (Ernest Rutherford, ค.ศ. 1911)
* **แนวคิดหลัก:** อะตอมมี "นิวเคลียส" ขนาดเล็กมากตรงกลาง รวมประจุบวกและมวลเกือบทั้งหมดไว้ ส่วนอิเล็กตรอนวิ่งวนในที่ว่างอันกว้างใหญ่รอบนอก
* **การแสดงผล 3D:** นิวเคลียสจิ๋วตรงกลางสีแดงสว่างจ้า ล้อมรอบด้วยที่ว่างขนาดใหญ่และมีอิเล็กตรอนวิ่งวนเป็นวงรีรอบทิศทาง
* **ข้อจำกัด:** ไม่สามารถอธิบายได้ว่าทำไมอิเล็กตรอนที่วิ่งวนจึงไม่แผ่รังสีแม่เหล็กไฟฟ้าแล้วตกลงสู่นิวเคลียส

### 4. 🪐 แบบจำลองอะตอมของนีลส์ โบร์ (Niels Bohr, ค.ศ. 1913)
* **แนวคิดหลัก:** อิเล็กตรอนโคจรรอบนิวเคลียสเป็นชั้นระดับพลังงานเฉพาะ ($n=1, 2, 3...$) โดยไม่สูญเสียพลังงาน และจะดูดกลืนหรือคายโฟตอนเมื่อย้ายชั้น
* **การแสดงผล 3D:** วงโคจรระดับพลังงานชั้น K, L, M ชัดเจน พร้อมเม็ดอิเล็กตรอนหมุนตามความเร็วระดับพลังงาน และสามารถจำลองการดูดกลืน/คายโฟตอนแสงได้
* **ข้อจำกัด:** อธิบายได้แม่นยำเฉพาะอะตอมที่มีอิเล็กตรอนเดี่ยว (เช่น ไฮโดรเจน) แต่อธิบายอะตอมที่มีหลายอิเล็กตรอนได้ไม่สมบูรณ์

### 5. ☁️ แบบจำลองกลุ่มหมอกควอนตัม (Quantum Cloud Model, ค.ศ. 1926 - ปัจจุบัน)
* **แนวคิดหลัก:** ชเรอดิงเงอร์และไฮเซนเบิร์กชี้ว่าอิเล็กตรอนเป็นทั้งคลื่นและอนุภาค ไม่สามารถระบุตำแหน่งและโมเมนตัมที่แน่นอนพร้อมกันได้ จึงอธิบายในรูป "กลุ่มหมอกความน่าจะเป็นในการพบอิเล็กตรอน (Orbitals)"
* **การแสดงผล 3D:** ละอองอนุภาคกลุ่มหมอกควอนตัมที่หนาแน่นใกล้ใจกลางและจางลงรอบนอก สอดคล้องกับกลศาสตร์ควอนตัมยุคปัจจุบัน

## 🔬 โหมดพิเศษ: ผ่าลึกนิวเคลียส & ควาร์ก (Quarks Zoom)
* จำลองอนุภาคมูลฐานตามแบบจำลองมาตรฐาน (Standard Model):
  * **โปรตอน ($p^+$):** $2 \text{ Up Quarks } (+2/3) + 1 \text{ Down Quark } (-1/3) \implies \text{ประจุ } +1$
  * **นิวตรอน ($n^0$):** $1 \text{ Up Quark } (+2/3) + 2 \text{ Down Quarks } (-1/3) \implies \text{ประจุ } 0$
  * แสดงเส้นแรงเหนี่ยวนำกลูออน (**Gluon Flux Lines**) และการสั่นไหวของแรงนิวเคลียร์อย่างเข้ม

## 📱 ระบบการควบคุมที่ออกแบบเพื่อมือถือและ AR
* **แตะส่วนประกอบในโมเดล -> อธิบายส่วนนั้นทันที:** แตะเม็ดโปรตอน, นิวตรอน, อิเล็กตรอน, ควาร์ก, หรือทรงกลม เพื่อเปิดการ์ดข้อมูลอธิบาย
* **แตะที่ว่างบนหน้าจอ = ไม่ขยับโมเดล (Do Nothing):** โมเดลจะอยู่นิ่งที่เดิมอย่างเสถียร
* **ปุ่ม [🎯 วางตรงหน้า]:** ปุ่มเฉพาะสำหรับนำโมเดลมาจัดวางตรงหน้าระดับสายตา
* **แผงความรู้และห้องทดลอง (Drawer ☰):** เปิดตารางสเปก, การจัดเรียงอิเล็กตรอน, และ Sliders ปรับโปรตอน/นิวตรอน/อิเล็กตรอนได้สดๆ
* **แบบทดสอบความรู้ (Quiz 🎓):** มินิควิซ 5 ข้อครอบคลุมทั้ง 5 แบบจำลองอะตอม พร้อมเฉลยละเอียด
